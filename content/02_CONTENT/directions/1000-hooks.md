# SleepAlb — 1,000 curiosity hooks

Spoken openers for Reels, Shorts, TikTok, and Pin titles.
Each line is supposed to leave a **gap**. If you add the reason in the same breath, you spent the watch.

Mothers, rotations, and the first-12-seconds hold: [`01-curiosity-patterns.md`](./01-curiosity-patterns.md).
How a finished post ships: [`00-sleepalb-direction-strategy.md`](./00-sleepalb-direction-strategy.md).

Do not run L0 critic on this file. Hooks are not captions.

**Count:** 1000 unique lines. 25 families × 40.
